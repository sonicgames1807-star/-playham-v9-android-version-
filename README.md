# Trace Neon

Откройте `index.html` в корне архива, чтобы посмотреть приложение. Для работы камеры на телефоне разместите файлы на HTTPS сайте (например, GitHub Pages) и разрешите доступ к камере.

Для публикации на GitHub загрузите **всё содержимое архива** в корень репозитория. В Settings → Pages выберите GitHub Actions. Исходники лежат в `source/`; workflow собирает их и публикует приложение.

Двойной клик по `source/index.html` не запускает приложение — это исходный файл для Vite.
